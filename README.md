# Web Draw — 网页绘画扩展

![Version](https://img.shields.io/badge/version-1.0.0-blue)
[![Releases](https://img.shields.io/github/v/release/taikdragon0-USA/browser-painting)](https://github.com/taikdragon0-USA/browser-painting/releases)

在任意网页之上用**触控笔**画画、标注、涂鸦。草稿锚定在**页面坐标**上,网页上下滚动时,草稿会**跟随网页内容一起移动**,而不是固定在屏幕某个位置。

- 支持 Chrome / Edge(Manifest V3)
- 原生 JS,无构建工具;仅导出功能打包一个 html2canvas(MIT)
- 智能输入:触控笔落下自动开始画(带 8192 级压感);手指触摸、鼠标滚轮照常滚动网页,无需手动切换模式
- 标注工具集:**6 种笔刷(含彩虹渐变)+ 4 种图形 + 文字 + 贴纸印章 + 橡皮擦**,自动保存草稿、一键导出全页截图

## 加载到浏览器

> 安装源二选一:① 直接用本仓库源码目录;② 下载 [Releases](https://github.com/taikdragon0-USA/browser-painting/releases) 里的 `browser-painting-vX.Y.Z.zip` 解压。两者都按下面的「加载已解压的扩展程序」选择对应文件夹即可。

### Chrome
1. 打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」,选择本目录 `G:\build\browser painting`
4. 打开任意网页,点工具栏上的扩展图标 → 出现浮动工具栏

### Edge
1. 打开 `edge://extensions`
2. 左下角打开「开发人员模式」
3. 点「加载解压缩的扩展」,选择本目录
4. 用法同 Chrome

## 数位板(高漫 1060 Pro 等)驱动设置

浏览器不依赖任何数位板厂商 SDK —— 数位笔经 Windows Ink 被原生识别为 `pointerType:'pen'`,压感走 `event.pressure`(0~1)。前提是**驱动配置正确**,否则可能收到的是鼠标模拟(无压感):

1. 打开高漫驱动控制面板(官网对应型号下载,装完重启)
2. **开启「Windows Ink」** ← 最关键,没开就没有压感,笔会变成鼠标
3. 工作模式选「**笔模式 / 映射模式**」,不要选「鼠标模式」
4. 可选:开启倾斜识别(供后续版本使用);工作区映射建议「全屏」

**自检**:装好驱动后,加载本扩展,用数位笔轻点(应出细点)、重压(应出粗线)。若整条线粗细不变,先回驱动面板核对上面 2、3 两项。

## 技术要点

- **滚动锚定**:笔迹以页面坐标(vector)存储;静态画布是**全页尺寸、绝对定位在文档流中**,由浏览器随网页内容**原生滚动** —— 快速滚动也零位移、零错位,不需要逐帧重绘。超长页面自动降分辨率以保证内存可控。
- **智能输入**:所有 pointer 监听挂在 `document` capture 阶段;触控笔落笔瞬间给 `<html>` 临时加 `data-dw-lock`(`touch-action:none`),冻结笔画期间的整页 panning,抬笔即释放;手指/鼠标完全放行。
- **压感**:`event.pressure` + 幂次曲线 + `getCoalescedEvents()` 高速采样,线条随压力平滑变宽。

## 已知限制

- 页面靠内层容器滚动(如 Notion、Google Docs 式布局)时,草稿无法跟随内容滚动(检测到会提示)。
- iframe 内的页面不绘制。
- 导出为"合成优先":复杂网页(跨域图片、复杂 CSS)html2canvas 渲染可能局部失真,失败时自动退回"纯草稿层" PNG。
- 套索若自相交,选中区域按"奇偶规则"判定,可能包含交叉形成的意外小区域。
- 贴纸/文字导出依赖系统彩色 emoji 字体,极简系统下可能显示为单色。
